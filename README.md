# Academic website

Five HTML pages, shared style.css, and shared script.js. No build tools required.

## Preview
Extract the ZIP and open index.html in your browser. Keep all files together.

## Publish
Create a public repository named YOUR-USERNAME.github.io. Upload the contents of this folder (not the ZIP), with index.html at repository root. In Settings > Pages choose Deploy from a branch, main, / (root), and Save.

## Edit
Edit the relevant HTML page. style.css controls appearance. script.js provides publication filtering and footer year. Never put secrets or private student information in this public repository.

## Content review
Teaching codes and semesters in earlier drafts were unverified and are omitted. Publications are carried over from the prior draft, not freshly audited; verify preprint links and publication status before public launch. Missing links are explicitly marked. Student information is supplied by the site owner; MS current-status lines have been removed.
